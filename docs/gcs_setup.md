# Google Cloud Storage Setup for Audio Files

This document explains how to set up Google Cloud Storage (GCS) for storing audio files generated by the TTS service.

## Overview

The application has been migrated from storing audio files in MongoDB to using Google Cloud Storage via Active Storage. This provides:

- **Scalability**: No document size limits
- **Performance**: Direct file serving from GCS CDN
- **Cost Efficiency**: ~90% cheaper than database storage
- **Reliability**: Enterprise-grade file storage

## Prerequisites

1. **Google Cloud Project**: You need a GCP project with billing enabled
2. **Service Account**: Create a service account with Storage Admin permissions
3. **GCS Bucket**: Create a bucket for audio files

## Setup Steps

### 0. 
```bash
bin/rails active_storage:install
bin/rails db:migrate
```

### 1. Create GCS Bucket

```bash
# Create bucket (replace with your project ID)
gsutil mb gs://youtupedia-audio-files-production

# Set appropriate permissions
gsutil iam ch allUsers:objectViewer gs://youtupedia-audio-files-production
```

### 2. Create Service Account

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Navigate to **IAM & Admin** > **Service Accounts**
3. Click **Create Service Account**
4. Name: `youtupedia-audio-storage`
5. Description: `Service account for audio file storage`
6. Click **Create and Continue**
7. Grant role: **Storage Admin**
8. Click **Done**

### 3. Generate Service Account Key

1. Click on the created service account
2. Go to **Keys** tab
3. Click **Add Key** > **Create new key**
4. Choose **JSON** format
5. Download the key file (e.g., `youtupedia-gcs-key.json`)

### 4. Configure Rails Credentials

```bash
# Edit Rails credentials
rails credentials:edit

# Add the following structure:
gcs:
  project_id: "your-gcp-project-id"
  keyfile_path: "path/to/youtupedia-gcs-key.json"
```

### 5. Environment-Specific Configuration

#### Development
```yaml
# config/storage.yml
development:
  service: Disk
  root: <%= Rails.root.join("storage", "audio") %>
```

#### Production
```yaml
# config/storage.yml
google:
  service: GCS
  project: <%= Rails.application.credentials.dig(:gcs, :project_id) %>
  credentials: <%= Rails.application.credentials.dig(:gcs, :keyfile_path) %>
  bucket: youtupedia-audio-files-<%= Rails.env %>
```

### 6. Install Dependencies

```bash
# Add to Gemfile
gem "google-cloud-storage", "~> 1.44", require: false

# Install
bundle install
```

## Migration from MongoDB

If you have existing audio files in MongoDB, use the migration script:

```bash
# Migrate existing files to GCS
rails audio_migration:migrate_to_active_storage

# Clean up old audio_content from MongoDB
rails audio_migration:cleanup_old_audio_content

# Verify migration
rails audio_migration:verify_migration
```

## Performance Benefits

| Metric | MongoDB Storage | GCS Storage | Improvement |
|--------|----------------|-------------|-------------|
| **File Size Limit** | 16MB | Unlimited | ∞ |
| **Storage Cost** | ~$0.25/GB/month | ~$0.023/GB/month | 90% cheaper |
| **Memory Usage** | High (full doc load) | Low (metadata only) | 95% reduction |
| **Network Transfer** | 3.4MB per request | Direct GCS access | 100% reduction |
| **CDN Support** | No | Yes | Global distribution |

## Troubleshooting

### Common Issues

1. **Authentication Errors**
   ```
   Error: Could not load the default credentials
   ```
   - Verify service account key path
   - Check GCP project ID
   - Ensure service account has Storage Admin role

2. **Bucket Not Found**
   ```
   Error: Bucket youtupedia-audio-files-production not found
   ```
   - Verify bucket name in storage.yml
   - Check bucket exists in GCP Console
   - Ensure bucket is in correct region

3. **Permission Denied**
   ```
   Error: Access denied to bucket
   ```
   - Check service account permissions
   - Verify bucket IAM policies
   - Ensure service account key is valid

### Debug Commands
